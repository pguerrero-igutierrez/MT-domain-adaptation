# Backtranslated Corpus

This directory contains the synthetic parallel corpora used for domain-specific fine-tuning. All files are generated by the translation scripts in `scripts/05–07`.

---

## Corpora

### `ca-literary_trilingual.json`

Trilingual CA–ES–EU literary corpus derived from the CTILC Catalan–Spanish literary dataset ([`guerreropaula/synthetic-corpus-ca-es`](https://github.com/guerreropaula/synthetic-corpus-ca-es)).

**Pipeline**: CA–ES source pairs → ES→EU translation (Latxa) → DP paragraph alignment (multilingual-e5-large) → trilingual records


**Notes**:
- `text_ca` is the high-quality original; `text_eu` is synthetic (machine-translated via Latxa from the Spanish pivot).
- During fine-tuning, the **back-translation** direction is EU→CA: model input is `text_eu` (synthetic source), target is `text_ca` (original reference).
- Paragraph alignment is performed per document using cosine similarity over multilingual-e5-large embeddings with a DP merge strategy (max 2 paragraphs merged per side).

---

### `eu-literary-EhuHac.jsonl`

Bilingual EU–CA literary corpus derived from the EhuHac Spanish–Basque literary dataset.

**Pipeline**: ES–EU aligned pairs → ES→CA translation (Latxa) → CA–EU synthetic records

**Notes**:
- `source_eu` is the high-quality original; `ca_translation` is synthetic.
- During fine-tuning, the **back-translation** direction is CA→EU: model input is `ca_translation` (synthetic source), target is `source_eu` (original reference).

---

### `eu-clinical_backtranslated.json`

Back-translated EU–CA clinical corpus derived from Basque clinical documents in the E3C corpus.

**Pipeline**: EU clinical documents → paragraph extraction → EU→CA translation (Latxa, with chunking for long documents) → CA–EU records



**Notes**:
- `eu` is the high-quality original clinical text; `ca` is synthetic.
- During fine-tuning, the **back-translation** direction is CA→EU: model input is `ca` (synthetic source), target is `eu` (original reference).
- Long documents were chunked at ≤2,000 characters before translation and rejoined to avoid context window truncation.


---

## Regenerating the Corpora

```bash
# Literary (CA source)
python scripts/05_translate-ca-literary.py --resume

# Literary (EU source)
python scripts/06_translate-eu-literary.py --resume

# Clinical
python scripts/07_translate-eu-clinical.py --resume --chunk-size 2000 --max-tokens 700
```

Use `--resume` to skip records already present in the output file.
